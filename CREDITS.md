# Credits

The list of repositories, commits, licenses and skill paths was taken from the public lock file of [universal-web-dev](https://github.com/generosomm/universal-web-dev) (MIT), which curated this set of skills first, and its README names the authors below. This project has not yet reviewed the pins itself (`reviewed` is `false` until a maintainer approves them).
